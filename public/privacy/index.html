プライバシーポリシー

最終更新: 2026-08-21

1. 収集する情報

当サイト（darekore.jp、以下「本サイト」）は、ユーザーから直接個人情報を収集しません。 お問い合わせをメールでいただいた場合は、返信と対応のためにその内容を利用します。

アクセス解析のため Google Analytics 4 を利用しており、閲覧ページ・滞在時間・ 使用デバイスなどの統計情報が収集されます。個人を特定する情報は含まれません。

2. Cookie の使用

Google Analytics 4 によるアクセス解析に Cookie を使用しています。 無効にする場合は、ブラウザの設定を変更するか、 Google アナリティクス オプトアウト アドオン をご利用ください。

3. アフィリエイト広告

本サイトは FANZA（DMM）および DUGA のアフィリエイトプログラムに参加しています。 本サイトのリンクを経由して商品を購入された場合、本サイトが紹介料を受け取ることがあります。 購入価格が変わることはありません。広告であるリンクには「広告」と表示しています。

4. 掲載情報の出典

掲載している出演者情報は、権利者が API で公開している項目をそのまま収録したものです。 推測による補完や、独自の評価・格付けは行っていません。

  • FANZA ActressSearch API
  • DUGA アフィリエイト Web サービス

写真は権利者が配信しているものを、そのまま参照して表示しています。 本サイトで保存・加工することはありません。

5. 訂正・削除のご依頼

ご本人および関係者の方から掲載を希望しない旨のご連絡をいただいた場合、 確認のうえ削除します。記載内容の誤りについても、同じ窓口で承ります。

info@darekore.jp

6. 第三者サービス

  • Google Analytics 4（Google プライバシーポリシー）
  • Google Search Console（検索での見え方の確認）
  • IndexNow（検索エンジンへの更新通知）
  • GitHub Pages（本サイトの配信）

7. 本ポリシーの変更

本ポリシーは予告なく変更することがあります。変更後はこのページに掲載します。
